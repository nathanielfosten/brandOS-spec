# Artifacts

Use this app to make a complete deliverable, such as an email, a deck or a page. Choose a starting point from [templates](templates/) and adapt it to the brief.

A template describes the structure of one kind of deliverable. It can use the [brand core](../../brand/) and [Signature Moves](../../signature-moves.md) directly. If it needs a component from the Components app, name that dependency in the template and reference its registry entry.

Save the finished work with the project it was made for. Keep the reusable original in the templates folder.
