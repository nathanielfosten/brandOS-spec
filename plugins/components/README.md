# Components

Use this plugin to find, preview and maintain pieces that can appear in more than one artifact, such as a button, a card or a chart.

- [Registry](registry/) describes each component by its intent and behavior so people, agents and tools can find the right piece across formats. Keep its implementation with the entry or link to it from there.
- [Sandbox](sandbox/) holds previews and working examples. When a component is ready to reuse, give it a registry entry.

Start from the brand’s [Signature Moves](../../signature-moves.md). Use the names from [brand styles](../../brand/styles/) for visual values and refer to [approved assets](../../brand/assets/) as needed.
